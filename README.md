# Message Board Test

Projeto simples para testar postagem de mensagens em uma tela — qualquer pessoa pode entrar e postar.

Como usar:

1. Instale dependências:

```bash
npm install
```

2. Inicie o servidor:

```bash
npm start
```

3. Abra `http://localhost:3000` no navegador. Abra em várias janelas/abates para ver atualizações em tempo real.

Observações:
- As mensagens ficam apenas em memória (reiniciar o servidor limpa o histórico).
- Não há autenticação intencionalmente — é um teste simples.
